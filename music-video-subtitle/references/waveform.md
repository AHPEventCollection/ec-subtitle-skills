# 编辑器波形

## 生成与交付

在完整MV任务中，取得唯一片源后、首次交付候选预览前运行：

```powershell
python -B $pipeline waveform --mv-dir $mvDir
```

入口进入项目绑定的media/base运行时，复用FFmpeg和ffprobe。业务实现随Skill放在`scripts/waveform.py`，单独复制本Skill即可使用；不从仓库根的web目录导入业务代码

输出在`review/preview/<视频名>.waveform.json`，与预览视频同名，例如`source.mp4`对应`source.waveform.json`。随完整视频和同名SRT或ASS一并交付，编辑器通过添加文件夹或批量选择文件读取波形；在线编辑器使用固定waveform.json文件名时，按其既有项目导入流程处理，不默认部署或上传

## 数据与时间基准

- 从预览视频首条真实音轨解码，不用歌词事件或字幕长度伪造波形，不为波形单独运行人声分离
- 数据只有`duration`和`peaks`，duration为完整媒体时长，单位秒；peaks为覆盖全片的等间隔0至1幅度值
- 默认每秒80点，超过50万点时降低密度，文件不超过10MB；静音全零有效
- 波形零点与预览视频及字幕一致，处理音轨起始偏移，首尾没有音频的区间补零，不把剪出的局部音频直接当整片波形
- 生成过程只解码音轨，不重编码预览视频、不修改字幕、不启动桌面播放

## 复用与验证

命令回读现有波形的时长、峰值范围、点数和大小，并检查片源修改时间；有效且未过期时直接复用。只修改字幕无需重跑。输入变更或旧波形损坏时，核对片源后使用`waveform --mv-dir $mvDir --refresh`显式重新生成，失败保留原有波形；新输出先完整写入临时文件再落盘，不留下可被编辑器误读的半成品

验证文件可被编辑器波形校验器读取、覆盖完整媒体时长，并通过已知静音与声音区段确认时间对应。实际播放、听校和字幕同步仍由用户完成，波形不产生人工验收结论

生成失败时明确说明波形缺项与错误，继续不依赖波形的工作；不把波形新增为发布或归档阻断条件。归档时保留预览目录中的波形作为工程材料
